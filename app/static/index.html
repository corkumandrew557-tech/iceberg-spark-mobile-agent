🚀 Iceberg Spark Mobile Agent

Version 0.1.0

A mobile-first agent interface for managing Apache Iceberg tables using Apache Spark, with Modal + Local Docker setup.

Features

  • Iceberg table management
  • Spark SQL query execution
  • Real-time data synchronization
  • REST API interface
  • Docker containerization

API Endpoints

GET /health
Health check endpoint
GET /api/v1/catalog
Get Iceberg catalog information
GET /api/v1/tables
List all tables in a namespace
GET /api/v1/tables/{table_name}
Get details of a specific table
POST /api/v1/query
Execute Spark SQL query
POST /api/v1/tables
Create a new table
